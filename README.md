## Usage

```sh
just dev     # local dev server
just build   # static site in dist/
```

Pages live in `src/content/docs/`. The Ansible pages are generated by
`scripts/generate_ansible_docs.py`; the pages workflow reruns it every Monday.

## Development

Run `just` for all recipes and `just check` before committing. Conventions: [Giftpilz0/shared](https://github.com/Giftpilz0/shared).
