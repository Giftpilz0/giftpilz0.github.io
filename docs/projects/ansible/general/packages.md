---
title: Packages Role
---

Install and manage RPM, Flatpak, and Python packages and repositories.

______________________________________________________________________

## Variables

| Variable                            | Type           | Options                       | Default                                                                                                                                                                                                                                                                   | Description                           |
| ----------------------------------- | -------------- | ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------- |
| `packages_package_state`            | string         | present, absent, latest, skip | present                                                                                                                                                                                                                                                                   | desired state of system packages      |
| `packages_rpmfusion_package_state`  | string         | present, latest, skip         | skip                                                                                                                                                                                                                                                                      | desired state of RPM Fusion packages  |
| `packages_additional_package_state` | string         | present, absent, latest, skip | present                                                                                                                                                                                                                                                                   | desired state of additional packages  |
| `packages_flatpak_package_state`    | string         | present, absent, latest, skip |                                                                                                                                                                                                                                                                           | desired state of Flatpak packages     |
| `packages_python_package_state`     | string         | present, absent, latest, skip | present                                                                                                                                                                                                                                                                   | desired state of Python packages      |
| `packages_package`                  | list of string | ---                           | ["curl","mkpasswd","python3-pip","rsync","zstd"]                                                                                                                                                                                                                          | list of system packages to manage     |
| `packages_rpmfusion_package`        | list of string | ---                           | `["https://mirrors.rpmfusion.org/free/fedora/rpmfusion-free-release-{{ ansible_facts['distribution_major_version'] }}.noarch.rpm","https://mirrors.rpmfusion.org/nonfree/fedora/rpmfusion-nonfree-release-{{ ansible_facts['distribution_major_version'] }}.noarch.rpm"]` | list of RPM Fusion packages to manage |
| `packages_additional_package`       | list of string | ---                           | []                                                                                                                                                                                                                                                                        | list of additional packages to manage |
| `packages_flatpak_package`          | list of dict   | ---                           | []                                                                                                                                                                                                                                                                        | list of Flatpak packages to manage    |
| `packages_python_package`           | list of string | ---                           | []                                                                                                                                                                                                                                                                        | list of Python packages to manage     |
| `packages_flatpak_repos`            | list of dict   | ---                           | `[{"name":"flathub","flatpakrepo_url":"https://dl.flathub.org/repo/flathub.flatpakrepo","state":"present"}]`                                                                                                                                                              | Flatpak remotes to add                |
| `packages_flatpak_repos_remove`     | list of string | ---                           | []                                                                                                                                                                                                                                                                        | Flatpak remotes to remove             |
| `packages_copr_repos`               | list of dict   | ---                           | []                                                                                                                                                                                                                                                                        | COPR repositories to enable           |
