---
title: Forgejo Role
---

Deploy the Forgejo Git service as a Podman quadlet.

______________________________________________________________________

## Variables

| Variable                      | Type           | Options     | Default                   | Description                                                                                                                                                                                                                  |
| ----------------------------- | -------------- | ----------- | ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `podman_user`                 | string         | ---         | `{{ ansible_user }}`      | system user for rootless podman operations                                                                                                                                                                                   |
| `forgejo_proxy_enabled`       | bool           | true, false | false                     | enable HTTP proxy for image pulls                                                                                                                                                                                            |
| `forgejo_proxy_http`          | string         | ---         | ""                        | HTTP proxy URL                                                                                                                                                                                                               |
| `forgejo_proxy_https`         | string         | ---         | ""                        | HTTPS proxy URL                                                                                                                                                                                                              |
| `forgejo_proxy_no_proxy`      | string         | ---         | ""                        | comma-separated list of proxy exclusions                                                                                                                                                                                     |
| `forgejo_network_enabled`     | bool           | true, false | true                      | create and manage the podman network                                                                                                                                                                                         |
| `forgejo_network_driver`      | string         | ---         | bridge                    | podman network driver                                                                                                                                                                                                        |
| `forgejo_network_name`        | string         | ---         | forgejo-internal          | podman network name                                                                                                                                                                                                          |
| `forgejo_bind_ip`             | string         | ---         | 127.0.0.1                 | host IP to bind exposed ports to                                                                                                                                                                                             |
| `forgejo_port_map_enabled`    | bool           | true, false | true                      | expose container ports on the host                                                                                                                                                                                           |
| `forgejo_port_map`            | list of string | ---         | ["3000:3000","2222:2222"] | host:container port mappings                                                                                                                                                                                                 |
| `forgejo_version`             | string         | ---         | 16.0.3                    | container image version                                                                                                                                                                                                      |
| `forgejo_autoupdate`          | bool           | true, false | true                      | enable podman auto-update for this container                                                                                                                                                                                 |
| `forgejo_db_host`             | string         | ---         | postgresql-pod            | PostgreSQL container hostname                                                                                                                                                                                                |
| `forgejo_db_name`             | string         | ---         | forgejo                   | database name                                                                                                                                                                                                                |
| `forgejo_db_user`             | string         | ---         | forgejo                   | database user                                                                                                                                                                                                                |
| `forgejo_db_password`         | string         | ---         | ""                        | database user password                                                                                                                                                                                                       |
| `forgejo_domain`              | string         | ---         | ""                        | external domain for the Forgejo instance                                                                                                                                                                                     |
| `forgejo_oauth_client_id`     | string         | ---         | ""                        | OAuth2 client ID for external authentication                                                                                                                                                                                 |
| `forgejo_oauth_client_secret` | string         | ---         | ""                        | OAuth2 client secret                                                                                                                                                                                                         |
| `forgejo_oauth_domain`        | string         | ---         | ""                        | OAuth2 provider domain                                                                                                                                                                                                       |
| `forgejo_oauth_name`          | string         | ---         | ""                        | OAuth2 provider display name                                                                                                                                                                                                 |
| `forgejo_oauth_admin_group`   | string         | ---         | forgejo-admin             | OAuth2 group that grants admin access                                                                                                                                                                                        |
| `forgejo_environment_vars`    | dict           | ---         | `{}`                      | extra environment variables injected into the container                                                                                                                                                                      |
| `forgejo_extra_files`         | list of dict   | ---         | []                        | list of arbitrary files to copy into the role quadlet directory. Each entry has src (controller path), dest (relative path inside the pod quadlet dir) and optional mount (container bind-mount path)                        |
| `forgejo_extra_dirs`          | list of dict   | ---         | []                        | list of arbitrary directories to copy into the role quadlet directory. Each entry has src (controller directory), dest (relative target directory inside the pod quadlet dir) and optional mount (container bind-mount path) |
