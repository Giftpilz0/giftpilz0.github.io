---
title: Cloudbeaver Role
---

Deploy the CloudBeaver database management web app as a Podman quadlet.

______________________________________________________________________

## Variables

| Variable                       | Type           | Options     | Default              | Description                                                                                                                                                                                                                  |
| ------------------------------ | -------------- | ----------- | -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `podman_user`                  | string         | ---         | `{{ ansible_user }}` | system user for rootless podman operations                                                                                                                                                                                   |
| `cloudbeaver_proxy_enabled`    | bool           | true, false | false                | enable HTTP proxy for image pulls                                                                                                                                                                                            |
| `cloudbeaver_proxy_http`       | string         | ---         | ""                   | HTTP proxy URL                                                                                                                                                                                                               |
| `cloudbeaver_proxy_https`      | string         | ---         | ""                   | HTTPS proxy URL                                                                                                                                                                                                              |
| `cloudbeaver_proxy_no_proxy`   | string         | ---         | ""                   | comma-separated list of proxy exclusions                                                                                                                                                                                     |
| `cloudbeaver_network_enabled`  | bool           | true, false | true                 | create and manage the podman network                                                                                                                                                                                         |
| `cloudbeaver_network_driver`   | string         | ---         | bridge               | podman network driver                                                                                                                                                                                                        |
| `cloudbeaver_network_name`     | string         | ---         | cloudbeaver-internal | podman network name                                                                                                                                                                                                          |
| `cloudbeaver_db_network_name`  | string         | ---         | ""                   | existing database network to join instead of creating one                                                                                                                                                                    |
| `cloudbeaver_bind_ip`          | string         | ---         | 127.0.0.1            | host IP to bind exposed ports to                                                                                                                                                                                             |
| `cloudbeaver_port_map_enabled` | bool           | true, false | true                 | expose container ports on the host                                                                                                                                                                                           |
| `cloudbeaver_port_map`         | list of string | ---         | ["8978:8978"]        | host:container port mappings                                                                                                                                                                                                 |
| `cloudbeaver_version`          | string         | ---         | 26.1.5               | container image version                                                                                                                                                                                                      |
| `cloudbeaver_autoupdate`       | bool           | true, false | true                 | enable podman auto-update for this container                                                                                                                                                                                 |
| `cloudbeaver_server_name`      | string         | ---         | CloudBeaver          | server display name                                                                                                                                                                                                          |
| `cloudbeaver_admin_user`       | string         | ---         | cbadmin              | admin username                                                                                                                                                                                                               |
| `cloudbeaver_admin_password`   | string         | ---         | ""                   | admin password                                                                                                                                                                                                               |
| `cloudbeaver_environment_vars` | dict           | ---         | `{}`                 | extra environment variables injected into the container                                                                                                                                                                      |
| `cloudbeaver_db_type`          | string         | ---         | postgresql           | database backend type                                                                                                                                                                                                        |
| `cloudbeaver_db_host`          | string         | ---         | localhost            | database host                                                                                                                                                                                                                |
| `cloudbeaver_db_port`          | string         | ---         | 5432                 | database port                                                                                                                                                                                                                |
| `cloudbeaver_db_name`          | string         | ---         | ""                   | database name                                                                                                                                                                                                                |
| `cloudbeaver_db_user`          | string         | ---         | ""                   | database user                                                                                                                                                                                                                |
| `cloudbeaver_db_password`      | string         | ---         | ""                   | database password                                                                                                                                                                                                            |
| `cloudbeaver_extra_files`      | list of dict   | ---         | []                   | list of arbitrary files to copy into the role quadlet directory. Each entry has src (controller path), dest (relative path inside the pod quadlet dir) and optional mount (container bind-mount path)                        |
| `cloudbeaver_extra_dirs`       | list of dict   | ---         | []                   | list of arbitrary directories to copy into the role quadlet directory. Each entry has src (controller directory), dest (relative target directory inside the pod quadlet dir) and optional mount (container bind-mount path) |
