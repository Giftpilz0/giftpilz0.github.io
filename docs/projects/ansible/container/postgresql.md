---
title: Postgresql Role
---

Deploy PostgreSQL as a Podman quadlet.

______________________________________________________________________

## Variables

| Variable                                | Type           | Options             | Default                                                                                                                                                 | Description                                                                                                         |
| --------------------------------------- | -------------- | ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `podman_user`                           | string         | ---                 | `{{ ansible_user }}`                                                                                                                                    | System user for rootless podman operations                                                                          |
| `postgresql_image`                      | string         | ---                 | docker.io/library/postgres                                                                                                                              | Image name without tag                                                                                              |
| `postgresql_version`                    | string         | ---                 | 18.6-alpine                                                                                                                                             | Container image version                                                                                             |
| `postgresql_autoupdate`                 | bool           | true, false         | true                                                                                                                                                    | Enable podman auto-update for PostgreSQL                                                                            |
| `postgresql_backup_autoupdate`          | bool           | true, false         | true                                                                                                                                                    | Enable podman auto-update for the backup container                                                                  |
| `postgresql_network_enabled`            | bool           | true, false         | true                                                                                                                                                    | Create and manage the podman network                                                                                |
| `postgresql_network_name`               | string         | ---                 | postgresql-internal                                                                                                                                     | Podman network name                                                                                                 |
| `postgresql_network_driver`             | string         | ---                 | bridge                                                                                                                                                  | Podman network driver                                                                                               |
| `postgresql_port_map_enabled`           | bool           | true, false         | false                                                                                                                                                   | Expose container ports on the host                                                                                  |
| `postgresql_bind_ip`                    | string         | ---                 | 127.0.0.1                                                                                                                                               | Host IP to bind exposed ports to                                                                                    |
| `postgresql_port_map`                   | list of string | ---                 | ["5432:5432"]                                                                                                                                           | Host:container port mappings                                                                                        |
| `postgresql_log_destination`            | string         | ---                 | stderr                                                                                                                                                  | PostgreSQL log destination                                                                                          |
| `postgresql_log_statement`              | string         | none, ddl, mod, all | none                                                                                                                                                    | SQL statement logging level                                                                                         |
| `postgresql_log_min_duration_statement` | integer        | ---                 | 1000                                                                                                                                                    | Log statements running at least this many milliseconds                                                              |
| `postgresql_log_connections`            | bool           | true, false         | true                                                                                                                                                    | Log successful connection attempts                                                                                  |
| `postgresql_log_disconnections`         | bool           | true, false         | true                                                                                                                                                    | Log session disconnections                                                                                          |
| `postgresql_log_checkpoints`            | bool           | true, false         | true                                                                                                                                                    | Log checkpoint activity                                                                                             |
| `postgresql_log_lock_waits`             | bool           | true, false         | true                                                                                                                                                    | Log waits exceeding deadlock timeout                                                                                |
| `postgresql_log_line_prefix`            | string         | ---                 | %m [%p] db=%d,user=%u,app=%a,client=%h                                                                                                                  | Context prefix for each PostgreSQL log line                                                                         |
| `postgresql_admin_database`             | string         | ---                 | postgres                                                                                                                                                | Administrator database created by the PostgreSQL image                                                              |
| `postgresql_admin_user`                 | string         | ---                 | postgres                                                                                                                                                | Administrator user created by the PostgreSQL image                                                                  |
| `postgresql_admin_password`             | string         | ---                 | ""                                                                                                                                                      | Password for the PostgreSQL administrator user                                                                      |
| `postgresql_users`                      | list of dict   | ---                 | []                                                                                                                                                      | Users to provision; each entry has name and password                                                                |
| `postgresql_databases`                  | list of dict   | ---                 | []                                                                                                                                                      | Secondary databases to provision and include in backups; each entry has name and owner                              |
| `postgresql_backup_schedule_times`      | string         | ---                 | 03:00                                                                                                                                                   | Time of day to run backup (HH:MM format)                                                                            |
| `postgresql_backup_retention_days`      | integer        | ---                 | 7                                                                                                                                                       | Number of days to keep backups                                                                                      |
| `postgresql_backup_compression`         | integer        | ---                 | 6                                                                                                                                                       | Gzip compression level (1-9)                                                                                        |
| `postgresql_environment_vars`           | dict           | ---                 | `{"POSTGRES_DB":"{{ postgresql_admin_database }}","POSTGRES_USER":"{{ postgresql_admin_user }}","POSTGRES_PASSWORD":"{{ postgresql_admin_password }}"}` | Extra environment variables for the container                                                                       |
| `postgresql_entrypoint`                 | string         | ---                 | ""                                                                                                                                                      | Optional PostgreSQL container entrypoint override                                                                   |
| `postgresql_backup_entrypoint`          | string         | ---                 | ""                                                                                                                                                      | Optional PostgreSQL backup container entrypoint override                                                            |
| `postgresql_extra_files`                | list of dict   | ---                 | []                                                                                                                                                      | Arbitrary file entries with src (controller path) or source (target path), dest, optional mount, mode, and template |
| `postgresql_extra_dirs`                 | list of dict   | ---                 | []                                                                                                                                                      | Arbitrary directory entries with src (controller directory) or source (target path), dest, optional mount and mode  |
