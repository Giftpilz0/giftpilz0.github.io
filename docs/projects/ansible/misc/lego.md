---
title: Lego Role
---

Issue and renew ACME certificates with Lego on Linux or Windows.

______________________________________________________________________

| Variable                               | Type           | Options                                        | Default                                                                                                               | Description                                                                       |
| -------------------------------------- | -------------- | ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| `lego_state_path`                      | path           | ---                                            | `{{ 'C:\\ProgramData\\lego' if ansible_os_family == 'Windows' else '/var/lib/lego' }}`                                | private shared Lego state directory containing account keys and certificates      |
| `lego_service_user`                    | string         | ---                                            | lego                                                                                                                  | Linux account used to run Lego                                                    |

| `lego_url`                             | string         | ---                                            | `https://github.com/go-acme/lego/releases/download/v{{ lego_tag }}/lego_v{{ lego_tag }}_linux_{{ lego_arch }}.tar.gz` | Linux Lego archive URL                                                            |

| `lego_binary`                          | path           | ---                                            | `{{ lego_path }}/lego`                                                                                                | Lego executable path                                                              |
