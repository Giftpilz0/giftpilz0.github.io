---
title: Snapper Role
---

Install and configure Snapper filesystem snapshots.

______________________________________________________________________

## Variables

| Variable                                 | Type         | Options     | Default                                                                                                                                                                                                                                                                                                                  | Description                                               |
| ---------------------------------------- | ------------ | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------- |
| `snapper_configs`                        | list of dict | ---         | `[{"name":"home","path":"/home","allow_users":"{{ ansible_user }}","sync_acl":"yes","timeline_create":"yes","timeline_cleanup":"yes","timeline_min_age":3600,"timeline_limit_hourly":5,"timeline_limit_daily":7,"timeline_limit_weekly":4,"timeline_limit_monthly":6,"timeline_limit_yearly":3,"number_cleanup":"yes"}]` | list of snapper configurations to create                  |
| `snapper_configs.name`                   | string       | ---         |                                                                                                                                                                                                                                                                                                                          | configuration name                                        |
| `snapper_configs.path`                   | string       | ---         |                                                                                                                                                                                                                                                                                                                          | subvolume path to manage                                  |
| `snapper_configs.allow_users`            | string       | ---         |                                                                                                                                                                                                                                                                                                                          | comma-separated list of users allowed to create snapshots |
| `snapper_configs.sync_acl`               | string       | yes, no     |                                                                                                                                                                                                                                                                                                                          | synchronize ACLs from subvolume to .snapshots             |
| `snapper_configs.timeline_create`        | string       | yes, no     |                                                                                                                                                                                                                                                                                                                          | enable timeline snapshots                                 |
| `snapper_configs.timeline_cleanup`       | string       | yes, no     |                                                                                                                                                                                                                                                                                                                          | enable automatic timeline cleanup                         |
| `snapper_configs.timeline_min_age`       | integer      | ---         |                                                                                                                                                                                                                                                                                                                          | minimum age in seconds between snapshots                  |
| `snapper_configs.timeline_limit_hourly`  | integer      | ---         |                                                                                                                                                                                                                                                                                                                          | number of hourly snapshots to keep                        |
| `snapper_configs.timeline_limit_daily`   | integer      | ---         |                                                                                                                                                                                                                                                                                                                          | number of daily snapshots to keep                         |
| `snapper_configs.timeline_limit_weekly`  | integer      | ---         |                                                                                                                                                                                                                                                                                                                          | number of weekly snapshots to keep                        |
| `snapper_configs.timeline_limit_monthly` | integer      | ---         |                                                                                                                                                                                                                                                                                                                          | number of monthly snapshots to keep                       |
| `snapper_configs.timeline_limit_yearly`  | integer      | ---         |                                                                                                                                                                                                                                                                                                                          | number of yearly snapshots to keep                        |
| `snapper_configs.number_cleanup`         | string       | yes, no     |                                                                                                                                                                                                                                                                                                                          | enable number-based cleanup                               |
|                                          |              |             |                                                                                                                                                                                                                                                                                                                          |                                                           |
| `snapper_enable_timeline_timer`          | bool         | true, false | true                                                                                                                                                                                                                                                                                                                     | enable the snapper timeline timer                         |
| `snapper_enable_cleanup_timer`           | bool         | true, false | true                                                                                                                                                                                                                                                                                                                     | enable the snapper cleanup timer                          |
| `snapper_add_to_fstab`                   | bool         | true, false | true                                                                                                                                                                                                                                                                                                                     | mount .snapshots subvolumes via fstab                     |
